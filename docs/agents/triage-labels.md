# Default triage labels

Use these seven existing GitHub labels as the default triage vocabulary.

| Label | Use |
|---|---|
| `bug` | Existing behavior is incorrect or broken. |
| `enhancement` | A requested capability or improvement. |
| `documentation` | Intent, guidance, examples or other documentation. |
| `question` | Information or a decision is needed to understand the request. |
| `duplicate` | Another issue already tracks the same work; link it. |
| `invalid` | The report does not describe a valid issue for this repository. |
| `wontfix` | An explicit decision has been made not to implement the request. |

Choose the label that best describes the issue. Labels describe triage; they do
not grant execution, approval, merge or deployment authority. Specialized labels
already defined in the repository may be used when relevant.
