# Proposal

## Why

The deployed wrapper retains repeated assessment loops and expensive context. Existing paid runs exposed late incompatible validation, schema friction and an artificial call cap; the owner also requires proper model-aware candidate understanding before filtering.

## What Changes

- Build a persistent native-tool candidate-understanding agent that accesses approved evidence and applicable canonical mathematical/statistical models, then reuses its cited digest across jobs.
- Project confirmed facts/preferences into auditable deterministic screening for seniority/years, region/remote/commute and work rights/hours; ambiguous cases remain explicit rather than invented exclusions.
- Finish the single native Evaluation agent using DeepSeek; remove supervisor/legacy assessment work from that path and provide focused validation feedback with canonical completion constraints.
- Account separately for digest, classifier, embeddings and job evaluation, including cold/reused costs; preserve Unlimited owner controls, checkpoint freshness, identity and exact approval boundaries.
- Verify existing failures offline before one controlled provider acceptance, complete release checks, deploy through the live native runtime and observe a canonical outcome.

## Capabilities

### New Capabilities

- `candidate-understanding`: approved evidence and model-aware digest lifecycle and screening-policy handoff.
- `job-assessment`: deterministic initial screening, native evaluation, accountable recovery and canonical result acceptance.

### Modified Capabilities

None; the initial OpenSpec capability inventory is empty. Existing source contracts and INTENT remain authoritative.

## Impact

Reuses candidate evidence/analysis/policy, prescreen engine/sync, model_insights, preference/outcome tools, agentic service/autonomous/runtime/persistence and model routing. No new dependencies or hosted tracing. Jev candidate-bearing features remain unavailable without an approved route; public classifiers remain scoped and accounted. Documents, browser submission and unrelated model roles are preserved; later career-stage expansion is outside this first slice.
